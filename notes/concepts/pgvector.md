# pgvector

## What is pgvector?

pgvector is a PostgreSQL extension that allows PostgreSQL
to store and search vector/embedding data.

In our project, it lets PostgreSQL store the embeddings
generated by Gemini and compare them with a user's query
embedding.

---

## What does it do in our project?

Our `Chunk` table contains:

embedding Unsupported("vector(3072)")?

This stores the 3072-dimensional embedding for each chunk.

---

## What happens during search?

Gemini:

User query
→ converts query into a 3072-dimensional embedding

PostgreSQL + pgvector:

Query embedding
→ compare against stored chunk embeddings
→ calculate vector distance
→ sort by closest
→ return top results

---

## Important distinction

### Gemini

Generates embeddings.

### pgvector

Stores embeddings and performs vector similarity/distance
calculations.

### Vector Search

Uses pgvector to retrieve the most relevant chunks.

### RAG

Uses vector search + retrieved context + LLM generation
to produce the final answer.

---

## In our project

Database:

PostgreSQL / Neon

Extension:

pgvector

Embedding model:

gemini-embedding-001

Vector size:

3072

Search operator:

`<=>`

`<=>` calculates cosine distance.

Lower distance = more similar.

---

## Simple mental model

Gemini = creates the coordinates

pgvector = stores and compares the coordinates

Vector Search = retrieves the nearest coordinates

RAG = uses the retrieved information to generate an answer
